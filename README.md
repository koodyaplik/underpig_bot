# underpig_bot

Telegram-бот для распознавания голосовых сообщений с помощью `faster-whisper`.

# Настройка Телеги

1. Создай бота

В @BotFather:

/newbot

Сохрани полученный токен.

Затем отключи Privacy Mode:

/setprivacy

Выбери бота и нажми:

Disable

После изменения Privacy Mode лучше удалить бота из группы и добавить снова.

## Запуск

1. Создайте локальный файл настроек:

```bash
cp .env.example .env
```

2. Укажите Telegram-токен в `.env`.

Если Telegram должен работать через SOCKS5-прокси, заполните также:

```dotenv
TELEGRAM_PROXY=socks5://user:password@host:port
```

Логин и пароль с зарезервированными URL-символами необходимо URL-кодировать.
DNS-запросы Telegram выполняются через прокси.

3. Запустите контейнер:

```bash
docker compose up -d --build
```

Модель сохраняется в локальном каталоге `models/`. Контейнер автоматически
запускается после перезагрузки, если Docker включён в автозагрузку.
