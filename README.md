# underpig_bot

Telegram-бот для распознавания голосовых сообщений с помощью `faster-whisper`.

## Запуск

1. Скопируйте `.env.example` в `.env`.
2. Укажите Telegram-токен в `BOT_TOKEN`.
3. Запустите контейнер:

```bash
docker compose up -d --build
```

Модель сохраняется в локальном каталоге `models/`. Контейнер автоматически
запускается после перезагрузки, если Docker включён в автозагрузку.
