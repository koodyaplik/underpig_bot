# underpig_bot

Telegram-бот для распознавания голосовых сообщений с помощью `faster-whisper`.

# Настройка Телеги

1. Создай бота

В @BotFather:

/newbot

Сохрани полученный токен.

Затем отключи Privacy Mode:

/setprivacy

Выбери бота и нажми:

Disable

После изменения Privacy Mode лучше удалить бота из группы и добавить снова.

## Запуск

1. Укажите Telegram-токен в .env
2. Запустите контейнер:

```bash
docker compose up -d --build
```

Модель сохраняется в локальном каталоге `models/`. Контейнер автоматически
запускается после перезагрузки, если Docker включён в автозагрузку.
